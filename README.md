# CCTV Group

Проектирование и строительство полного цикла.

Статический сайт: HTML, CSS и JavaScript. Сборка не требуется.

- `index.html` — главная страница.
- `pages.html` — внутренние разделы и проекты; маршруты задаются после `#`.
- `assets/` — фотографии, видео, логотипы, шрифты и документы.
- `css/` и `js/` — стили и поведение сайта.

## Разделы

`pages.html#about`, `#contract`, `#business`, `#home`, `#telecom`, `#projects`, `#documents`, `#clients`, `#partners`, `#careers`, `#contacts`, `#privacy`. Проекты открываются маршрутом `pages.html#project-<slug>`.

## Хостинг

Загрузите содержимое репозитория в корневую директорию статического хостинга. Главная точка входа — `index.html`. Сохраните структуру каталогов и регистр имён файлов. Для локального просмотра можно выполнить `python3 -m http.server 8080` в корне сайта.

Используются GSAP, ScrollTrigger и Lenis с CDN. Маршруты внутренних страниц работают через hash и не требуют серверных rewrite-правил.

## Формы и материалы

Формы проверяют обязательные поля и показывают подтверждение на стороне браузера. Серверная отправка заявок, файлов и резюме пока не подключена; её нужно настроить перед приёмом реальных обращений.

Часть фотографий, отзывов, благодарственных писем и проектных параметров подготовлена для макета. Перед использованием сайта как официального источника эти материалы и юридические тексты необходимо подтвердить у владельца компании.

Старые варианты дизайна и рабочие экспорты не входят в опубликованную версию. Их локальная резервная копия сохранена отдельно от сайта.
